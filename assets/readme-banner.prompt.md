# README banner generation

Tool: built-in image_gen.

Use case: ads-marketing.
Asset type: final hero poster for the GitHub README of a real open-source Linux backup tool, PasarGuard Backup Manager.
Primary request: a minimal, modern, professional WIDE banner, approximately 3:1 aspect ratio, ideally 2400 by 800 pixels. Full-bleed opaque background.
Art direction: premium software identity, precise editorial typography and generous negative space. Deep near-black navy background (#090D18), restrained cyan and soft violet accents matching a terminal UI. A very subtle broad indigo glow behind the right-side symbol; mostly flat, clean background. Refined and quiet, not flashy.
Composition: spacious asymmetric layout. The left 60 percent contains the complete typographic lockup, aligned left, with ample 8 percent edge margins. The right third has one elegant abstract emblem: a small stack of archived data blocks protected by a simple shield-shaped frame, with one delicate paper-plane outline lifting away to suggest delivery to a Telegram channel. The archive and shield use restrained satin cyan-to-violet edges and soft depth, with clean geometry. Keep the emblem compact, sophisticated, and subordinate to the title. Thin, precise details that remain legible when the whole banner is displayed at 900px wide.
Text (verbatim, exactly these three text elements, no other text):
"PasarGuard"
"Backup Manager"
"Encrypted backups. Delivered to Telegram."
Set PasarGuard as a bold, beautifully kerned off-white geometric sans-serif title. Backup Manager immediately beneath it, smaller and medium weight, in pale cyan. The single-line tagline underneath has comfortable separation, in smaller muted light gray sans-serif. Flat typography facing the viewer, never perspective or distorted. Ensure perfect spelling, sentence punctuation and high readability.
Constraints: original design; no borrowed logos, no brand imitation, no screenshots, no browser window, no terminal code, no badges, no buttons, no fine-print, no watermarks, no border around the full canvas. No photography, no people, no padlock clipart, no scattered icons, no busy starfields, no circuit-board textures, no grid, no excessive bloom. Strong balance, excellent spacing, clean usable README artwork.
